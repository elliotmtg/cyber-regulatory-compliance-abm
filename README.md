# Cybersecurity Regulatory Compliance ABM

An Agent-Based Model built with Mesa simulating the interactions between Regulators, Software Producers, and Users across pre-incident (normal operations & regulatory compliance dynamics) and post-incident (breach response, remediation, fines, and recovery) phases.

## Requirements
- Python 3.11+
- mesa==2.3.0
- pandas
- numpy

## Setup
```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```
